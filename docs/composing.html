How a frame of the desktop is composed - without the GPU, and with it

The same six stages each time something on the desktop changes. What moved, step by step on the M700 (17 October 2026), is who does each stage: from the processor doing all of them, to the display and the blitter taking three, to the render engine taking the composing itself. Why the blitter cannot do all of it

Gen9's blitter copies and fills but does not blend. Composing is mostly blending - shadows, rounded corners, text, translucent bars - so the blitter can take only the opaque parts (6b), and the rest waits for the render engine: shaders, a pipeline, a context - the same work 3D needs.

What stayed the same in every column

Applications draw into their own regions, the window manager describes, the window server owns the screen - control by message, pixels in shared memory. The GPU took stages over without any application changing: each step swapped who does a stage, behind the same doors.
