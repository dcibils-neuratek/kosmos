GPU Monitor - what it stands on

It measures nothing itself. The GPU's driver reads the display engine's and the GT's own counters - clock, sleep, flips, frames, underruns - and keeps a table of the buffers it made and who holds each; Nebula reads the one counter only ring 0 can, the GPU's energy. GPU Monitor asks once a pace and draws. The desktop's label is the window manager saying what it already knows.
