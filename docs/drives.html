Kosmos Drives

A design, 14 September 2026, and its decisions taken with Diego the same day. Nothing here is built yet. The copy in the repository is docs/drives.html.

Two pieces, both borrowed. Tracker shows your drives the way every desktop does: a list of drives, and inside each one, its files. Drives, a new app, shows the drives themselves: type, partitions, filesystems and sizes.

What Tracker would look like

Three groups in the sidebar, in this order: Places for where you work, System folded away, and Drives for what is plugged in - every filesystem with its type beside its name. Click Drives and every drive is listed with how full it is.

Home under Places is a shortcut straight to the home folder here. Programs keep using /home as they do today, so nothing that works now changes.

Your own places

A place is a shortcut you make. Drag PHOTOS 2024, or any folder on it, into Places and call it MyPhotos: it sits beside Home, and one click takes you there.

MyPhotos is a shortcut, not a second copy
Places › MyPhotosPoints at PHOTOS 2024, or at a folder inside it, like PHOTOS 2024 › Italy.
Drives › PHOTOS 2024Still listed here, as it always is.

Unplug the drive and MyPhotos stays in Places, greyed out, saying the drive is not plugged in. Plug it back and it works again. That is what Finder's Favorites and Windows' Quick Access do, and why they are not mount points: nothing about the drive changes.

Instead of drive letters

A program needs a path to reach a file, so every filesystem it can read has one. Kosmos gives each a named folder, the way macOS and BeOS do, rather than a letter.

Your files, on the boot drivePHOTOS 2024, a USB drive
WindowsC:\Users\diegoE:\Italy
macOS/Users/diego/Volumes/PHOTOS 2024/Italy
BeOS/boot/home/PHOTOS 2024/Italy
Kosmos/home/drives/PHOTOS 2024/Italy

/drives is one folder every program has from the moment it starts. Drives plugged in or pulled out appear and disappear inside it, so a program that is already running still finds a drive plugged in after it. A program never given /drives cannot reach any drive at all.

From an app

An app's Open and Save windows have the same sidebar as Tracker: Places and Drives. You go through whichever is quicker. What the app gets is the file itself, at its real place on the drive, so no app has to know that MyPhotos exists.

At the prompt there is no sidebar, so a file is typed by where it really is: /home/notes.txt, or /drives/PHOTOS 2024/Italy/IMG_2211.JPG. Today's /home paths stay exactly as they are.

One Open and Save window, for every app

Every system has one, so every app opens and saves the same way. Kosmos has its start already: /lib/panel.lua, after BeOS's file panel, a window each app opens for itself. The editor, Photo, Reader and the PDF viewer use it. It is small: a folder list, Up and Home, and a name when saving.

  • Hands the app one full path, or nothing if you close it - has it
  • The sidebar: Places and Drives - as in Tracker
  • Sizes, kinds and icons in the list - as in Tracker
  • New folder - from inside the window
  • Only the files an app can open - Photo shows pictures, the music player shows songs
  • Asks before replacing a file that is already there
  • Read-only drives shown as read-only, and a save there refused with a sentence
  • Remembers the last folder each app used

And every app that opens or saves uses it. Paint cannot open or save a picture at all today; the music player, play and the Super Nintendo take a file only when they are started with one. Each gets an Open, and Paint a Save.

The Drives app

Tracker is for your files. Drives is for the drives themselves: every drive this machine found, what kind it is, how big, how it is split into partitions, and the filesystem in each. The same tool Haiku calls DriveSetup, Windows calls Disk Management and macOS calls Disk Utility.

Decided, 14 September

  1. The sidebar is Places, System, Drives, and every filesystem says what it is.Drives, not Devices: in Kosmos, devices already means the processor, the screen and the keyboard. System comes after Places, folded by default. Each filesystem shows its type beside its name - kfs, FAT32, exFAT, NTFS.
  2. A drive with one filesystem opens straight into its files.A drive with two, like your boot stick, first shows the two.
  3. The Desktop gets a disk icon for each driveas BeOS did, in place of today's single Drive icon that opens everything at once.
  4. The Drives app shows before it changes anything.Drives, partitions, filesystems and sizes first; formatting and partitioning later, each on its own.
  5. Places are shortcuts you add and name.Drag a drive or a folder in and call it MyPhotos. A shortcut rather than a mount, so the drive itself never changes.
  6. One Open and Save window for every app.The one Kosmos has, grown to what any system's does, and every app that opens or saves moved onto it.
  7. Other machines' filesystems are read only: FAT32 and exFAT.Kosmos's own readers, from Microsoft's specifications. NTFS is left out for now: a filesystem of that type is listed with its type, and not opened.
  8. Tracker shows where you are as the whole trail.From the sidebar's group down to the folder you are in - Drives › Kingston DataTraveler › KOSMOS HOME, or Places › MyPhotos › Italy - as in the pictures above, rather than a raw path like /home.
