Kosmos Preferences

One place to configure Kosmos, divided by part. Drawn on 23 September 2026, before any of it is built — roadmap.md 5zh, agreed with Diego the same day. Every row on this page is a setting that exists in Kosmos today; under each group is the file it lives in now. Nine categories: the desktop’s icons and the Deskbar are under Appearance, because they are what the machine looks like.

Why this is a list and not a server

The open question on this was where the settings should live: a window that reads and writes each app’s own file is a second copy of every format, and one that owns them all is a settings server and a protocol — which is the shape this system normally reaches for.

The survey answered it, and the answer is neither. Every settings file in Kosmos is already the same format: a Lua table written with fs.write and read back with fs.read, through the system’s own serialiser. There is no second format to copy, because there is only one.

What is missing is not storage. It is a list of what there is — which file, which key, what kind of thing it is, and one line saying what it does. Preferences renders from that list; every app goes on reading its own file exactly as it does now.

So the work is a schema in one place, and it is the part to get right:

The last row is the finding. opt/kosmos/smp, video=WxH and irq=pic can only be set by rebuilding a stick or editing a line on one. They are marked boot in the mockup: shown, explained, and needing a restart. A machine you can only configure by rebuilding it is the thing Preferences exists to end.

What is deliberately not here

No settings that belong to one window. A Terminal’s own text size stays in that Terminal’s View menu, because it is a property of this window and not of the system; Preferences sets the default a new one starts at. The same rule decides every borderline case: if changing it should change one window, it is not here.

No search results page, yet. The search field is drawn because the screenshot has one and because a list this long wants it, but what it searches is the schema above — so it is one function over a table, and it arrives with the table rather than before it.

The aesthetic

Flatter and quieter than Kosmos draws today: one accent, rounded groups of rows, a sidebar with no tree, and chrome that is a title and two icons. That is a shading decision, which beos.md has always said is ours to make fresh — roadmap.md 5zi. What it deliberately does not touch is behaviour: replicants, the Deskbar, the right button reaching the application. Those are BeOS decisions about how the desktop works, and a screenshot is not asking for them.
