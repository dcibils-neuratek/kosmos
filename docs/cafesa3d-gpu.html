What's yours to decide

  1. E1, how the tracer's kernel is written: in Kosmos's own kernel language, C-shaped, compiled on Kosmos to eu.lua's assembly and checked by the driver like any kernel (recommended); or Mesa's compiler on the Mac from OpenCL C, which needs a GPU address space per program first; or a smaller tracer by hand in assembly.
  2. E2: Preview first, held pixel for pixel, then Final (recommended); or both at once.
  3. E3: an emulator of the execution units on the Mac, so make test runs every kernel - the tracer's included - without a GPU (recommended).
  4. E4: until image textures reach the GPU (R7), a textured object drawn in its base colour, said in the window (recommended); or the GPU refused for such a scene.
