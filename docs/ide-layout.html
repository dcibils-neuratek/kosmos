Kosmos IDE Layout

What changes

  • The tools are Write's: a small icon with its word under it, 56 pixels wide each, in one row 64 pixels high. Today's wide buttons with their keys written beside them take about twice the room; the keys move to the More menu and to the foot. The row has room left for what comes next.
  • New ▾ is a tool, and New Project is in it.
  • The header keeps what is open, whether it is running, Find a file and ⋯ More. The state pill moves up from the tools.
  • Find opens a bar under the tools: matches marked in the editor, which one of how many, up and down, match case, this file or the whole project, and Replace beside it. Project results go to the Search tab, a click on one opening it at its line.
  • The sidebar's Project tab shows only the project. Kosmos's own Apps, Programs, Libraries, Kits and Templates move to a System tab, read-only, opened in the editor as they are now.
  • Console joins Output, Problems and Search below: what a running program prints and the lines you type to it, when it asks.

What's yours to decide

  1. The tools as drawn: New ▾, Open, Save · Undo, Redo, Find · Build, Run, Stop, Check, then Console and Sidebar at the right. Recommended.
  2. The More menu instead of a menu bar, since Kosmos took menu bars out on 23 September. Recommended. A menu bar would bring back what the look removed.
  3. The sidebar's third tab, System, holding Kosmos's own files. Recommended, as you described it.
  4. Find as a bar under the tools, with This file and Project in one bar. Recommended.
