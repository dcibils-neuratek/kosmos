# JetSki W7: a browser to use every day

Written 14 November 2026, the day Diego made it the work: "Let's finish the
browser now end to end which is the most importante part of the os now for
a daily driver usage". `webkit.md` is the design and `webkit.html` the
window, both agreed on 11 November. This file is the order W7 and W8 are
built in, step by step, and what each step's test is.

## The order: the processes first

`webkit.md`'s order holds. Diego confirmed it on the same day, choosing it
over a browser in one process. The reason is in WebKit's source: the curl
loader that ran inside a page's process (`ResourceHandleCurl`, for
WebKitLegacy) has been removed upstream. Today's curl loader is
`NetworkDataTaskCurl`, and it lives in WebKit2's network process. A browser
in one process would need a loader of our own, a second copy of that one,
thrown away when the processes arrive. So:

1. **W7a, the three processes.**
2. **W7b, pages from the network**, through WebKit's own loader.
3. **W7c, the window.**
4. **W7d, what a day of browsing needs.**

## W7a: the three processes

WebKit2 (`ENABLE_WEBKIT`). The UI process is JetSki itself. Each tab has a
web process running WebCore and JavaScriptCore. One network process runs
curl.

- **`IPC::Connection` on Nebula's endpoints.** A message is a call or a
  pulse, and anything larger is a region whose handle travels with it
  (*Control by message, data by shared memory*). A port's connection is
  `Platform/IPC/<port>/ConnectionPort.cpp`; Kosmos's is written for
  endpoints.
- **The process launcher** on `SYS_SPAWN`, with a role, one image
  (`jetski.elf`) started three ways. Each process gets only the
  capabilities its role needs: the network process the Network Kit, a web
  process none of the disk.
- **A read-only region in Nebula** (`roadmap.md`, W6b's follow-ups):
  WebKit's `SharedMemory` hands out read-only views.
- **Test, `x86-webkit2`**: WebKit's own MiniBrowser shape, headless. The
  UI process starts a web process and a network process and loads a
  recorded page; its picture, read back through a region, must be the one
  W6 paints. The control is a web process ended halfway through: the UI
  process must say so, and load the page again in a new one.

## W7b: pages from the network

The network process's `NetworkDataTaskCurl`, as WebKit ships it, over the
POSIX layer's sockets on the Network Kit:

- HTTPS on OpenSSL, with Mozilla's roots as
  `/Kosmos/Settings/ssl/cert.pem`. `br`, gzip and deflate decoded.
- Cookies in curl's `CookieJarDB` on SQLite, under
  `/Home/Settings/JetSki/`.
- The HTTP cache, WebKit's own, on disk.
- Nothing waits: the network process answers on its own threads, and a
  web process never blocks on it (*Nothing waits on hardware*).
- **Test, `x86-sites`**: the recorded sites served over HTTP and HTTPS by
  a server on this Mac, and loaded by URL. Each must paint as it does from
  files. The control is the server answering 404 for one style sheet, and
  the picture must differ. Then the live sites on the M700, outside the
  gate.

## W7c: the window

`jetski.elf`, an installed application (`docs/elf.md` step 5), opens the
window `webkit.html` drew: tabs in the window's band and an address field.

- **Painting**: each web process paints into a region, and the UI process
  hands it to the window manager as the window's surface. Tiles and the GPU
  come from the *Fast* section and are measured after.
- **Input**: keys with text input, the pointer and its cursor shapes, the
  wheel and scrolling, selection, and copy and paste through the window
  manager's clipboard.
- **The address field**: a URL, or words searched for.
- **Test, `x86-jetski`**: the window driven by the display harness. Open a
  recorded site, scroll, click a link, type into a search field, go back,
  and copy text out. Each is checked against the screen.

## W7d: what a day of browsing needs

- Tabs: open, close, and switch with keys.
- Back and forward, history, and the address field completing from them.
- Bookmarks, as files in `/Home`.
- Downloads into `/Home/Downloads`, shown as they arrive.
- Find in page, zoom, and printing to PDF through the PDF Kit.
- The session restored after any stop: every window and tab.
- A page that says why a certificate was refused.
- HTTP/2, with nghttp2 held to its own tests.
- A tab whose web process ended shows a page saying so, with Reload.

## W8 and video

The live sites on the M700, as `webkit.md` lists them. Content blockers on
with EasyList (`ENABLE_CONTENT_EXTENSIONS`), on by default and switchable
per site. Video, `media.md`: M2 `<video src>` once W7c has a window to
show it in, M3 MSE, M4 Opus and the clock, and M5 YouTube live on W7b's
loader.
