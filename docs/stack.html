A message says what; a region holds the bytes

Control by message, data by shared memory: a frame, a period, a packet or a block never travels as a message. Single-producer, single-consumer rings carry them.

A kit is code you run; a server is someone you ask

Kits and libraries run inside your process. Servers and drivers are processes of their own, reached by a message in a declared shape.

Capabilities by index

A system call names a slot in the caller's own table. There is no global name to guess, and no ambient authority.
