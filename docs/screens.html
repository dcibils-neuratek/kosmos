Remote Screen

Another computer's screen in a Kosmos window - your Mac's, over VNC - with this machine's keyboard and pointer sent back to it. The other side of what vncd already does for the M700. Drawn before it is built; the name is a working one, yours to change.

Connected to the Mac, fitted to the window

The Mac's 3440 by 1440 screen, scaled to fit the window and kept to its shape, with a sliver of dark either side. The header says whose screen it is; Fit and Actual size switch between this and one pixel to one pixel, scrolled; Control off makes it view only, so a stray key cannot type into the Mac; Keys sends what the M700's own desktop would otherwise keep (Command-Tab, Command-Space, Command-Q); the button at the right ends it. The pointer is the Mac's, drawn by the Mac. The line at the foot says how it is going, as the Servers window does for vncd: the encoding, frames a second and the rate, quietly.

The Keys menu

Keys the M700 itself answers to, sent to the other machine instead. While the window has the focus, everything else typed goes to the Mac as it is - Super as Command, so Super-C copies there - except Super-Tab and the launcher pad's key, which stay Kosmos's, so the way out of the window is never lost.

The first window: what is on the network, what was used, or an address

On this network is every machine that says it shares its screen (_rfb._tcp, which mdnsd already hears). Recent is what was connected to before, in the settings kit's file. Choosing one fills the form; an address can be typed instead. The password is the one the Mac's Screen Sharing sets under "VNC viewers may control screen with password", and kept in the keyring if asked - never in a settings file. Double-clicking a machine connects at once when its password is kept.

When the Mac says no

Said as it is, with the next step: a wrong password; a machine that answers but only offers Apple's own sign-in, which the first version does not speak; one that does not answer at all. A connection that drops while in use says so over the last picture, greyed, with Connect again.

Full screen

The Mac's screen as the whole of the M700's, at the M700's 1720 by 1440: scaled to fit, the header gone, and a small bar that slides down from the top edge when the pointer rests there - the same three controls, and Leave full screen. Super-F, or the bar's button, goes back.

What it does

  • Shows another computer's screen, as it changes, fitted to the window or at actual size.
  • Sends this machine's keys and pointer to it, or only watches.
  • Finds machines sharing their screen on the network, remembers the ones used, and takes an address.
  • Signs in with a VNC password, kept in the keyring if asked.
  • Says how it is going: the encoding, frames a second, the rate.
  • Full screen, and back.
  • Later, not in the first version: Apple's sign-in with the Mac's own account; the clipboard both ways; more than one screen at once.
