Network Monitor

What goes in and out of this machine, now and over the last minute, as Monitor shows the processors: the card and how fast it is going each way, a graph of each, the totals since the machine started, and which programs' connections the traffic is.

As it opens

The card says what the network is - its maker and model, how fast its link is, this machine's address - and on the right how fast it is going now, in in blue and out in orange, the same two colours all the way down. The graph is the last minute: what came in rises above the line, what went out hangs below it, both on one scale that fits the busiest second and says so at its edge. The totals are since the machine started: bytes and packets each way, and how many were dropped - by the card or the stack - because nothing should be dropped and when something is, it is worth seeing. The connections are every open one, the program that holds it, where it goes, its state, and its rates each way now; the busiest first.

The dots' menu

The same three paces as Monitor, and whether rates are in bytes or bits - a link is sold in bits a second, a file is measured in bytes, and both are right.

Asked for, not sent: Network Monitor asks the server once a pace for its counters - a message of numbers, one request - and works out the rates itself as the difference between two readings, the way Monitor works out a processor's share. Nothing is sent to it unasked, and the server keeps nothing for it but the running totals it keeps anyway.
