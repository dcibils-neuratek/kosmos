Text Editor

Drawn on 28 September 2026, before any of it is built — roadmap.md 6zs. Diego: “the edit app is now worthless as the ide replaced it with a real Lua editor”, so “convert edit into a Text Editor app that allows the user to write simple documents in either plain text or markdown”. Editor becomes Text Editor: for letters, notes and lists rather than programs, which the IDE has. It keeps the icon it already wears, BeOS's StyledEdit — and this is StyledEdit's job, with Markdown where StyledEdit had its own styles.

A Markdown document

Markdown is shown as it is written, and styled while it is written. What is on the disk is what is on the screen: the # and the asterisks stay, faint, so nothing is hidden and nothing is converted — while the heading is large, the bold is bold and the code is in the mono face. The markers of headings and lists hang in the margin, so the words line up down the page.

The header is the title bar: the document’s name, what it is and how long, and whether it has changed since it was saved; then Text | Markdown, Save and the dots — three controls, the rule every window keeps (docs/desktop.html). The text sits in a column about seventy characters wide in the middle of the window, however wide the window is, with no line numbers: those are the IDE’s. A checkbox is clicked to tick it, which writes the x into the file. Find and replace opens under the header and closes with Escape.

A plain text document

Nothing is interpreted. A # is a character and a dash is a dash; the text is in the look’s text face, or the mono face if Monospaced text is ticked — kept per document, beside it, as the look keeps its faces. The same window, with Text chosen.

What it understands

The Markdown people write in notes, and no more. Reader’s parser, markdown.lua, has most of it, and drops the asterisks of bold because “this font has one weight” — true when it was written, and not since the Plex family arrived with its bold and its italic.

Return at the end of a list item starts the next one, numbered or ticked the same way; Return on an empty item ends the list. The formatting keys work in Markdown and do nothing in plain text, where there is nothing to format.

Editor, Reader and the IDE

A Lua file is the IDE’s; a document is Text Editor’s. Editor’s Run goes, since running a program is what the IDE is for, and Editor’s opens txt lua conf becomes opens txt md conf log — so a .md double-clicked in Tracker opens to be written in, and a .lua opens in the IDE. Reader stays what it is: the guides that ship in the image, read and not written, and Open with still offers it for a Markdown file.

What it costs. The kit’s editor draws every line in one face at one size, colouring spans — which is all the IDE needs. A styled Markdown line needs two things it does not do: a face per span (Plex Sans regular, bold, italic and bold italic, and Plex Mono, are all in the image already), and lines of different heights, for the headings. That is the one real piece of work, in ui.lua’s editor; the rest is markdown.lua learning bold, italic, links and checklists, and a window of about the size Editor is now.

Plain text needs none of it, so it can come first: Text Editor with Text only, then Markdown on top.

To decide

Each is drawn above as recommended. Answer by number.

  1. Text Editor replaces Editor, with the StyledEdit icon it has now. Its file becomes /Kosmos/Apps/texteditor.lua and wm texteditor starts it.

    A launcher or a startup list naming editor is found by its new name the way /bin/clock.lua still is, rather than rewritten.

  2. Markdown is styled as it is written, the marks kept faint — the first toggle above.

    The second hides them except on the line with the caret, which reads cleaner and hides what is on the disk. A side-by-side preview is the third way, and the one this does not recommend: two copies of every line, and the one you read is not the one you type in.

  3. The marks of headings and lists hang in the margin, so the words line up down the page.
  4. A column about seventy characters wide, in the middle of a wide window, and no line numbers.
  5. One window per document, as StyledEdit had — not tabs, which the IDE has for a project.
  6. A new document is Markdown, saved in /Home/Documents. A document’s format follows its name when opened, and Text | Markdown switches it; Save as gives it the other ending.
  7. It opens txt md conf log, and .lua goes to the IDE; Editor’s Run goes with it.
  8. Reader stays, for the guides that ship, and Open with offers it; Text Editor is where a .md opens.

    Or Reader folds into Text Editor as a way of reading a document, and there is one application fewer.

  9. Plain text first, then Markdown, each landing on its own — since only Markdown needs the editor to learn faces and heights.
