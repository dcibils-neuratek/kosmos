F - a frame of Chromium

  1. F1 Chromium draws the frame into its buffer, in the guest.
  2. F2 the guest's virtio_gpu asks the changed rectangle transferred and flushed.
  3. F3 the monitor copies it from the guest's RAM into the screen's region - C, a row at a time.
  4. F4 a pulse tells the Linux window which buffer, with the damage beside it.
  5. F5 the window blits the rectangle into its surface (C) and commits it.
  6. F6 the window manager composes it on the screen.
