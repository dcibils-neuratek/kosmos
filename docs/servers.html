From the Mac

None of the three needs a program of ours on the other side: a browser for the web server, any terminal for the command line, macOS’s own Screen Sharing for the screen. For what is run from a script, tools/kosmos_telnet.py knows where a command’s output ends, and fetches files.

~/Code/kosmos $ python3 tools/kosmos_telnet.py find

What is Diego’s to decide

  1. A password for the screen. The command line has none, by his choice. VNC’s protocol offers none or its own password; macOS’s Screen Sharing asks for one and may refuse a server that offers none. So the Screen page has a Password row: required, or allowed to be empty the way the command line is.
  2. A viewer may look, or control too, by default. Drawn as View only, with the Deskbar’s mark letting one viewer type when that is wanted.
  3. What else is a server here. Three to start. Candidates later: files to another machine (a folder of /Home over SMB or WebDAV, so the Mac’s Finder mounts it), and the Lua push this session’s roadmap already has, which rides on the command line.
  4. The Web Server application goes, its page here taking its place, rather than two ways to do one thing.

How it works

PartWhat it is
A serverA program of its own, as httpd and telnetd are now, which writes its state and its last lines to /Temporary/<name>. It does not know a window is watching.
This windowA manager, as the Web Server app is: it starts a server, ends it, and reads what it wrote. Running is a process of that name existing, not what a file last said.
Its settings/Home/Preferences/servers, one table a server; what starts with the machine is read from it at boot, and a development stick’s telnetd=23 still starts the command line whatever it says.
The screenRFB 3.8 (RFC 6143), a server in C: the window manager’s composed screen lent to it to read — every window’s pixels, so a grant like the others — only the rectangles that changed sent, and keys and the pointer coming back the way the USB keyboard and mouse do.

What exists today: httpd and its Web Server window, and the command line — telnetd, tools/kosmos_telnet.py and make remote-profile, started by itself on a development stick. The Servers window and the screen are this drawing, to be changed until it is right.
