Magnet

Windows put into place by where they are dropped: a window dragged to the right edge shows the right half it would take, and takes it when let go; to the top, the whole room; to a corner, a quarter. The same from the keyboard - Super with the arrows - and a page in Preferences to turn it on and off and say what the edges and keys do. After Magnet for the Mac, which Diego named on 10 October 2026: "dragging a window to the right of the screen will show that it can be docked and occupy that half of the screen", "dragging a window to the top of the monitor will allow you to maximise it", "is called 'magnet' and i like that as a feature and a preferences pane to configure it", "it can be turned on and off", "dock a window to the right can be used with a key combination like super+right arrow".

How it is made

The window manager's, which already moves, resizes and maximises windows and knows the room left by the strip and the dock (OUT.room, maximise). The outline is a picture of its own, composed by the window server like the resize outline is. A window that draws its own pixels is told its new size as it is when maximised (handlers.surface), and one that cannot resize is moved only. The settings live with the rest of the window manager's (/Home/Preferences), read at its start and changed live from the page.
