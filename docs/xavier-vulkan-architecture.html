T - a token written

  1. T1 The sampler chose the last token; its embedding row and position become push constants.
  2. T2 The token's command buffer, recorded once: 28 layers of norm, products, RoPE, attention, SwiGLU, add.
  3. T3 One submit, one fence. No message for each product, as X7 had.
  4. T4 The EUs read the 0.93 GB of weights; the stream never leaves the GPU.
  5. T5 The logits, 600 KB, read from a cached buffer; the sampler as it is.

Q - a question read

  1. Q1 The same layers, mul_mm in place of the matrix-vector product: a batch of the question's tokens a submit, each weight read once for all of them.
