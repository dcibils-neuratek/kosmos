Xavier - what it stands on

Xavier holds no model: it asks one server, /Running/llm, through one door, and reads the answer out of the region the server hands back. The model is loaded once for every application that asks - Write, Mail and the IDE after Xavier. The LLM Kit does the arithmetic in C; the window is Lua and no weight passes through it. A word of the answer (A) never travels in a message; the window (W) waits on the server and draws what arrived.

A - a word of the answer

  1. A1 The server steps the model one token - every weight read once, 1.6 GB at 4 bits - and takes the likeliest.
  2. A2 Its text is appended to the answer's region and written published after a barrier. Nothing is copied into a message.
  3. A3 A held WAIT is answered: only how far it got.

W - the window

  1. W1 A question is one ASK: the text, the most tokens, stop at a blank line.
  2. W2 WAIT, held by the server until there is more; then the new bytes read from the region.
  3. W3 Stop is a message, answered at once.
