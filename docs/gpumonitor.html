GPU Monitor

The graphics processor: how busy each of its engines is, how fast it runs and how long it sleeps, what it draws from the power supply, the memory it holds and who holds it, and what the display is doing - its refresh, its flips, and whether the desktop is drawn with the GPU's help.

And: "i need to know if kosmos is using gpu acceleration on the desktop in some way, like a label somewhere in the desktop, perhaps beside the kernel version".

As it opens, on the M700

The GPU in a card, its maker small above its model, and on the right how busy it is and how fast it runs now. Busy, a graph a minute long, with a chip for each engine above it - render, blitter, video - and an engine Kosmos sends no work to yet says so rather than showing a zero that means nothing. Clock and sleep: the GPU's speed over the minute, and under it how much of each second it spent asleep (RC6), which is what an idle GPU does. Memory: the GPU's buffers over the minute, against the memory it can address. The display: flips a second against the refresh, and frames held back. Down the right, the facts as Windows lists them - utilisation, clock, power, memory, the display - and what the desktop is drawn with, the same words the desktop's label says. Underneath, who holds the GPU's memory: each buffer, its holder, its size and what it is for.

The label on the desktop

Kosmos 0.11.265 | v0.10.187-640 | 2026-10-17 | PC x86-64 | GPU: HD 530 - cursor plane, page flips

Beside the version, at the bottom right of the desktop as it is now: what draws the desktop. Under QEMU, GPU: virtio - cursor, or GPU: none - software. When the render engine composes (step 7) it says 3D compositor. The window manager knows each of these already; the label is a few lines in it, and GPU Monitor's "Desktop drawn with" says the same.
