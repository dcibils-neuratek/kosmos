Mail on WebKit - what it stands on

One WebKit in Kosmos, one image it runs in, and one door to it. JetSki and Mail both run inside the image and make views through the WebKit Kit. A message's view runs no scripts, answers cid: itself and holds every network load until Load Pictures is pressed.

M - opening a message

  1. M1 Mail hands the message's HTML to its view once, as a string, with the message as its base.
  2. M2 The web process parses, styles, lays it out and paints it. No script runs.
  3. M3 A cid: picture is asked for; Mail answers with the part's bytes and type.
  4. M4 A network picture is held by the rule: no request leaves the machine until Load Pictures.
  5. M5 The painted page is copied into Mail's surface, as JetSki's is.

L - a link pressed

  1. L1 The kit reports the address; the pane stays on the message.
  2. L2 Mail hands it to the open JetSki, which opens a tab, or starts one.
