Shortcuts - what it stands on

Every key Kosmos answers to, in one window. Nothing in it is a list of its own: the desktop's keys come from the window manager that takes them, text's from the UI kit that answers them, and an application's from its own header, which the kit also uses to draw its menus and answer its keys. Shortcuts is Lua, and the thinnest layer there is.

S - a key typed into the search

  1. S1 The query in words, each with its spellings from keys.chord; a few hundred rows matched - under a millisecond.
  2. S2 The twenty rows that fit drawn: keycaps and a line of text each, the matched words lit.
  3. S3 One commit; the window manager composes.

O - opening, under 200 ms

  1. O1 One message: the window manager's keys.
  2. O2 About sixty headers, each read to its first line of code; icons decoded once.
