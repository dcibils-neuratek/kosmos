Tracker's list view

Every name cut cleanly at its column's edge, never under the next one; columns that are dragged wider and narrower by their headings' edges; and Created and Modified, date and time, for every folder.

Diego, on the M700, 10 October 2026: "The tracker list view needs some work", "for big files the name overlaps the size", "the columns are not resizable", "it needs more columns like created at, modified at (Date time) fields".

As it opens

Name, Size, Kind, Modified, Created. A long name ends in an ellipsis at its own column's edge - the full name is in the status bar when it is chosen, and in a tooltip after half a second over it. Sizes right-aligned, so the digits line up. Dates in a sentence a person reads at a glance: Today, 21:34, Yesterday, 09:12, then 8 Oct 2026, 14:05; this year's dates without the year would be shorter, and is left out on purpose, because a column whose rows are differently shaped is harder to read down.

A column dragged wider

The pointer over the line between two headings becomes a two-way arrow; pressing and dragging moves that edge, with a guide down the whole list and the width beside it. Every column to the right moves with it; none of them changes size. A double-click on an edge fits the column to its widest entry. Name never gets narrower than 120, the others than 60; the list scrolls sideways when the columns are wider than the window, rather than squeezing.

The headings' menu

A right click on any heading. Each column shown or hidden - Name always shown, so it is greyed - and a few more a person might want: Added (when it arrived in this folder), Location in a search's results. Then where the widths are kept.

Where Created and Modified come from

  • On the disk (/Home, diskfs): Modified is the inode's mtime. Created is new, and kept as an attribute the disk server writes once when a file is made - kfs already keeps attributes on every inode, so the disk's format does not change. A file made before has none and shows its Modified, in grey.
  • On a share (SMB): the server says both, and the SMB client passes them on.
  • On a drive (FAT32, exFAT): both are in the directory entry already.
  • In memory (`/Temporary`) and the program store: Modified only; Created shows a dash.

What it is made of

  • Columns become one piece of the UI kit: headings whose edges drag, a cell cut with an ellipsis, widths kept. Tracker draws its own rows today, as Processes and Mail draw theirs - three copies of the same idea - so the columns are written once in the kit and Tracker is its first user; Processes and Mail move onto it after.
  • Cut with an ellipsis by ui.fitted, which exists and measures in the face's own pixels.
  • The dates through clock.lua, which already says today and yesterday for Mail.
  • The widths in Tracker's settings (prefs.lua), or as an attribute on a folder that keeps its own.
