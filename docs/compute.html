The kernel

// each thread: a pixel's c, then z = z² + c
mul (16) r10  r0.1  16          // x of the group
add (16) r10  r10   r2.0        // + lane
mad (16) r12  r1.0  r10  r1.2  // cx
mad (16) r14  r1.1  r0.6 r1.3  // cy
mov (16) r16  0.0              // zx, zy, n
loop:
mul (16) r20  r16  r16        // zx²
mul (16) r22  r18  r18        // zy²
add (16) r24  r20  r22
cmp.l (16) f0.0  r24  4.0     // still inside?
...
send.dc1 (16) null r40  // the colour, to buffer 0
send.ts (16) null r112 {EOT}

The renderer chosen in the Render menu, the processor's staying beside it; the same scene rendered by each, the times side by side, and the GPU's picture held to the processor's so a faster wrong picture is never shown as a win. A ray tracer is a far larger kernel than the fractal's: it waits on the kit, the example, and a way to write kernels bigger than assembly by hand (compute.md, D1).
