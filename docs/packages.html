Packages

Everything Kosmos can install, from a package server (the Mac, for now): what is installed and from which build, what has a newer version, and what is not installed yet. Install, Update and Remove each a click. A package carries a manifest saying what it is, which build it is for, its files and where they go, what powers it needs, and what other packages it depends on. Installing one brings what it depends on, and removing one says what still needs it: APT's shape, for Kosmos.

Dependencies as APT has them: installing a package installs what it depends on first, in one confirmation that lists everything and the total. Removing one that another installed package needs says so and offers both. Remove takes exactly the files the manifest lists, never a whole folder's contents: what a person made beside them is theirs.

What a package is: its manifest

package.txt· inside quake.zip
# Made by tools/packages.py from user/installed/Quake/quake.lua's header
name        quake
title       Quake
kind        game
about       id Software's Quake, the shareware episode
version     0.11.174
protocols   7f3c9a1e        # this build's protocol stamp: refused by another
into        /Home/Apps/Quake
needs       audio display input
depends     # nothing
file        quake.lua        13 102  sha256 9b1e...
file        quake.elf    11 422 864  sha256 51c0...
file        id1/pak0.pak 18 689 235  sha256 e3a7...

A zip with its folder and this file. Plain text, a line a fact, so another machine can check it: the files with their sizes and sums, so a download that was cut short is known before anything is replaced. Not typed by hand: name, title, icon and needs are already in the application's header (-- kosmos: name, icon, needs, image), and the build writes the manifest from them, so the two cannot disagree. The server's index is every manifest's first lines, as APT's Packages file is.

pkg is the window's other face, as netstat is Network Monitor's: pkg lists, pkg install, pkg remove, pkg update. The window calls the same library, so the two cannot disagree.
