The Plex theme

Colours, fonts and spacing, all taken from the mockups, and all written in one theme file. Where the mockups disagree, or don't draw something, this page says so and asks.

What a theme file becomes

Today a theme is 22 colours (24 with the Deskbar's own two). From now on it's complete: colours, then a face and a size for each of the five roles, then the spacing. Every theme names all of them, so nothing depends on a default nobody can see. Photon, BeOS, Platinum and IRIX get today's fonts and spacing written in, and look exactly as they do now.

name        = plex
desktop     = #3d63b8
window      = #f4f4f1
...
font.ui      = ibmplexsans 16
font.title   = ibmplexsanscondensed 14
font.heading = ibmplexsans-semibold 15
font.text    = ibmplexsans 16
font.mono    = ibmplexmono 12
...
pad         = 12
gap         = 12
row_pad     = 7

Built, 22 September

The colours, the five faces and the spacing inside a widget - list rows, buttons and fields - are in Plex. Still open: the spacing between widgets, pad and gap above. Each application lays itself out with its own numbers - Appearance 12 and 10, Music and Shortcuts 14, the Deskbar 4 - so making them one theme-wide value would change some applications under every theme, not only Plex.

Decided, 22 September

  1. Widget text is Plex Sans 14, as the style guide has it - and then 16, the same morning, on the ThinkPad: "fonts look smaller than on qemu so the default font size for regular and widgets is 16". The defaults every other theme uses went to 16 with it.
  2. Reading text is Plex Sans 16, as the pages have it. The Terminal and code stay Plex Mono.
  3. Headings are Plex Sans SemiBold 15, and the SemiBold file joins the ones Kosmos carries.
  4. No rounded corners and no shadow for now: square, flat, and the colours, fonts and spacing above.
