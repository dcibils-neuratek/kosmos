Kosmos IDE tutorial

Fourteen lessons that build real applications for Kosmos in its IDE, from a window with a button to a world in 3D: first in Lua, then with C. Each ends by showing the application Kosmos itself ships that does the same thing for real, so its own applications become your worked examples.

Every lesson builds one small application, step by step, with the code in front of you. Its finished project is in the IDE too: open the three dots at the right of the IDE's header, then Lesson's Project, and choose the lesson - it is copied into /Home/development, where you can run it, read it and change it.

Open this tutorial again at any time with F1 in the IDE, or from the three dots, then Tutorial.

Later parts

Part two draws pixels - a sketchpad and a falling-blocks game. Part three adds C - Mandelbrot timed in Lua and in C, and a window drawn entirely from C. Part four uses the system's kits - sound, the network, compression, a camera and 3D.

Three words first

A project is a folder of your application's files. The IDE shows it on the left, under Project.

An application is a program with a window. In Kosmos it is written in Lua, and its first lines say so: -- kosmos: application.

A kit is code Kosmos supplies for your application to use - the UI kit for windows and buttons, the gfx kit for pixels, and many more. You reach one with use.
