How fast a drive is, the way CrystalDiskMark shows it - and, because this is the tool Kosmos's storage is being made fast with, where the time went, and whether a change made it faster.

The window

Pick a drive or a filesystem, a size and how many runs, and press Start. Each row reads and writes one way; the best run is kept. A row Kosmos cannot run yet says so, instead of showing a number for something else.

A drawing, not a screenshot, and the numbers are examples. Clicking a number shows its row's layers below the grid. The size menu offers only sizes that fit in the free space of what was picked, since a file is written to measure writing.

What it can be pointed at

A drive is measured by reading its blocks directly, so its numbers are the device and its driver. A filesystem is measured through a test file, as CrystalDiskMark does. The difference between the two, on the same drive, is what the filesystem costs.

Before and after

Every run is saved as a file with its drive, size and Kosmos version as attributes, so Tracker can list them. Pick two and the window shows what changed. This is how each step of making storage fast is shown to have worked, or not.
