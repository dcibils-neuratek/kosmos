Looking for computers every few seconds/Network

What a computer is comes from what it announces (mDNS, which mdnsd already hears): file sharing (_smb._tcp), screen sharing (_rfb._tcp), and what kind of machine it is (_device-info._tcp - a Mac's model, or Kosmos). One computer announcing several things is one card. A computer you are signed into is ringed and says how many shares; double-click it and its shares open as folders, as they do today. A computer not signed into opens the sign-in card. This machine is not listed - it is the one you are sitting at.
