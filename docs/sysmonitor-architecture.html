System Monitor - what it stands on

It counts nothing itself. Nebula, the GPU's driver, the network server, each drive's server and the LLM server count, as they do for today's monitors. System Monitor asks each of them once a pace. A new library turns two readings into rates, a new C kit keeps the history and draws it, and the pages are the old windows' bodies moved in. Four windows go once every row they show has a place here.

O - the Overview, once a second

  1. O1 The window kit's clock, at the pace.
  2. O2 The totals asked: two syscalls to Nebula, and about a dozen messages, one to each counting server - each a fixed shape. A source slow to answer is asked less often until a call with a deadline exists.
  3. O3 meters.lua takes the differences; about 80 numbers pushed into the Series Kit's rings, no table made for history.
  4. O4 The page that shows is painted: cards and text by gfx, each graph one series:draw in C.
  5. O5 The surface committed to the window manager.

Aim: the whole second under 5 ms on the M700, to be measured in S3, not claimed.
