B Build - F6, or Run after a C change

  1. B1 the IDE calls cc.build{ sources, out, kit } - in its own process
  2. B2 TinyCC compiles each .c with /Kosmos/Developer's headers 3 ms a small file
  3. B3 links them with the runtime, unpacked once a boot 20-40 ms on the Mac
  4. B4 the header stamped; problems handed back as a table
  5. B5 the image written to the project's folder, from a region the slow step
  6. B6 Problems at their lines, or "Built, 20.1 MB" in Output

R Run - F5

  1. R1 the IDE starts the project's Lua, as Run does today
  2. R2 its header names mandelbrot.elf; the launcher reads it
  3. R3 the loader holds it to Kosmos's rules and starts it 0.1-0.3 s
  4. R4 the Lua runs inside it; use("mandelbrot.elf") is its C - and the window opens
