A - a key in a long file

  1. A1 the key reaches the editor.
  2. A2 textbuf changes one line.
  3. A3 lualex colours it, and the next only while a line's end state changed.
  4. A4 the rows on the screen are drawn.
  5. A5 completion looks the prefix up.
  6. A6 on a pause, Lua's parser; on save, luacheck in its own process.

Nothing in A1-A5 grows with the file. Measured on ui.lua, 10,708 lines, on the M700, in I1.

B - a save, the preview restarted

  1. B1 the file is saved.
  2. B2 the running app is ended.
  3. B3 it is started again, with its console and inspect doors.
  4. B4 the window manager hosts its first frame where the last was. No pixel crosses to the IDE.
