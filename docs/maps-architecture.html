Maps - what it stands on

A native map: OpenStreetMap's vector tiles read from a PMTiles archive, decoded and drawn in C by a new Map Kit, through new anti-aliased paths in gfx, into a window that draws its own pixels. Maps itself is Lua - what a person does - and the thinnest layer there is.

F - a frame of a drag

  1. F1 Maps works out which tiles are on the screen at this zoom and where - about twelve at 1720 by 1440.
  2. F2 For each, tile:draw: the style's rules in order - land, water, parks, buildings, road casings, roads.
  3. F3 Each rule is one coverage buffer filled by gfx's paths and blended once.
  4. F4 The labels: placed when a tile arrives, moved by the drag, drawn as text.
  5. F5 One commit; the window manager composes.

Nothing on this path decodes, reads the disk or waits on the network: tiles are decoded once and kept.
