Corona - what it stands on

A third desktop for Kosmos: CDE's Front Panel, workspaces and Motif frames with IRIX's Toolchest, Desks Overview and sculpted icons - and in 2026 a media workstation's, with what is playing, its levels, a record button and the processors, the GPU and the sound's deadline in the panel. One window manager under every desktop, a file naming Corona's shell, and every new piece built below the desktop so that Astra, Pewter and the applications can use it too.

L - levels moving, every frame

  1. L1 The mix, in the AUDIO band, writes each stream's peak and the master's left and right into the meter page once a period, under a sequence count.
  2. L2 No message: the Front Panel mapped the page once, read-only.
  3. L3 Each frame it reads a few dozen bytes and draws two meters, 18 by 52 points, into its own surface; the window manager composes that rectangle.

D - a song dropped on the Front Panel

  1. D1 Tracker starts a drag of kind files; dropped on Now Playing, the window manager hands the panel the path.
  2. D2 filetypes.lua: a song is Music's, a film Video's.
  3. D3 The panel posts transport{ play = path } to Music's name, launching it if it is not running, and paints the song at once.
  4. D4 Music's media.lua opens the file on the Playback Kit and describes its stream.
  5. D5 The audio server carries the description; the panel, Pewter's bar and the lock screen read it.
