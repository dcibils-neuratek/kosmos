This Machine

Every piece of hardware the machine has, seen at once: what it is, where it sits, whether Kosmos drives it and with what, and what it is doing - grouped by kind, filtered to what has no driver in one press, and the full text report behind a button.

Diego, 18 October 2026: "lets redesign the about this machine app to show all hardware components detected, driven and not driven in a visual and nice way so i can see all the hardware my computer has, usb drives and devices, disks, network, cpu, gpu, memory, audio, etc", "mockup first".

As it opens, on the M700

The machine in a header: its name as the firmware gives it, Kosmos's version, and three counts - devices, driven, no driver yet. A filter: All, Driven, No driver. Every device as a card, grouped by kind, each with a picture of what it is, its name, where it sits - a PCI address, a USB port - a pill for its state - green "Driven by" and the driver's name, grey "Detected, no driver" with the class it reported, blue "In use" where it is busy - and a line of what it is doing now. Other is what the bus has that belongs nowhere else - the chipset's bridges, the management engine, the SMBus. A stick plugged in appears while the window is open.
