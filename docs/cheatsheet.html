Kosmos

Two halves: what you type at the prompt, and what you do on the desktop. The same page is in the machine - type help "shell", and the quotes are not decoration, which is explained at the end of the first half.

One - at the prompt

The line you are typing

  • up and down - the lines typed before, thirty-two of them
  • backspace - the only editing there is; there is no cursor
  • Control-C - abandon the line and start a fresh one

Moving around

  • pwd - where you are
  • cd path - somewhere else; cd alone goes to /
  • ls path - one level
  • tree path - all of them, from here down

Reading

  • cat path - the whole thing; a value, so a table prints as one
  • head -n 5 path - the first lines, ten by default
  • tail -n 5 path - the last ones
  • wc path - lines, words and bytes
  • grep pattern path - the lines that match, with their numbers
  • du path - how much is under each directory in here

Changing

  • touch path - an empty file
  • mkdir path - one directory, no -p
  • cp from to - a directory as the destination means "into it"
  • mv from to - rename and move are the same operation
  • rm -r path - -r is the program walking, not a flag a server has
  • save path text - write a line and read it back
  • edit path - the editor, in a window

What a file is, rather than what is in it

  • stat path - kind, size, and where the bytes are
  • which name - where a program is, if it is anywhere
  • attr path - its attributes
  • attr path kind=note - set one; one name=value a word, so no spaces in a value
  • find kind=note - everything that matches, anywhere that can answer

The machine

  • ps - what is running, with an id and a band each
  • kill id or name - end one; two of a name is a refusal, not a guess
  • df - what each mount holds, and what the disk has left
  • neofetch - the short answer
  • machine - the long one, including what it cannot be asked
  • mem and cpu - memory, processors
  • devices - every device, and whether a driver claimed it
  • diskinfo - what is on the disk

Starting the desktop, and anything on it

  • wm - the desktop: the icons, and the Deskbar that starts things
  • wm doom - that program and nothing else; wm desktop,deskbar names several
  • wm tracker:/bin - a program with something to work on, after the colon
  • monitor 30 & - a trailing ampersand detaches it and gives the prompt back
  • Control-C - end what is running and take the screen back

Where things live

  • /bin /lib - the programs and libraries in the image
  • /home /user /system - the disk; these survive a reboot
  • /ramfs - memory; this does not
  • /dev /net /app - devices, the network, the running applications

/ is not a filesystem. It is a list of mounts, each answered by a different server, and ls / shows exactly the ones the process asking was handed.

Two rules that will catch you

A line with Lua punctuation in it is Lua, not a command. grep [ f is evaluated and fails; /grep [ f runs the program. The same rule is why help fs is a syntax error while help "fs" and /help fs both work - help names a value in the shell, so a bare word naming it goes to Lua.

There are no pipes and no redirection. The bar and the angle bracket are not spelled differently here, they are absent - a shell that composed programs that way needs a stream between two processes, and what this system has between processes is messages and shared memory.

Deliberately missing

chmod, chown, sudo, useradd - there are no users and no permission bits. What you may reach is decided by the capabilities you were handed, which is not something a command can change.

man is help. ln - no links in the filesystem. hostname - nothing here has a global name. env and export - no environment variables. sort, cut, sed, awk, tee - pipeline tools, and there are no pipes yet.

Two - on the desktop

The desktop itself

  • What it shows - /home/Desktop, and nothing else
  • Drag an icon anywhere and it stays: the place is kept on the file, as desktop_x and desktop_y, so attr shows it and a copy carries it
  • Drag onto a folder's icon - the file moves into that folder
  • Drag onto the Trash - thrown away, under a free name if it holds that one already
  • Drive - a launcher that opens Tracker at /
  • cheatsheet.html - this page, put back whenever it is missing
  • Open a folder - a Tracker window opens; the desktop stays the desktop
  • The picture behind the icons - Appearance, under Preferences in the Kosmos menu, lists the PNGs in /home

Launchers - an icon that starts a program

  • launcher /home/Desktop/Doom doom - make one
  • launcher /home/Desktop/Notes editor /home/notes.txt - everything after the program is its arguments, spaces and all
  • launcher --icon App_Terminal path program - choose its picture: a name from assets/icons without the .png
  • Run it again on the same path to change what it starts
  • attr path - a launcher is a file with attributes and nothing inside: kind=launcher, program, args, icon
  • It starts what the Deskbar could start, and nothing the Deskbar could not

The Trash

  • Delete in a Tracker window moves what is selected into the Trash
  • Delete inside the Trash is the one that does not come back
  • File > Empty Trash - all of it, for good
  • Its icon is full or empty by what is in it, and it is a folder like any other: open it and drag things back out

A Tracker window

  • < > Up Home New folder Delete - the buttons across the top
  • Search - narrows the listing as you type
  • File - Open, New folder, Rename, Cut, Copy, Paste, Select all, Select none, Delete, Empty Trash
  • Go - Back, Forward, Up, Home, Refresh
  • View - as icons, as list, and By name, By size or By kind
  • Enter opens, Control-R renames, Control-A selects all, Escape selects none, Backspace goes up
  • Drag files into a folder, into another window, or out onto the desktop

The bar across the top

  • Kosmos, at the left - Applications, Demos, Preferences and System, each item with its own picture; Restart and Shut Down under a line at the bottom
  • Right-click Kosmos - Reload Menus after you change the folder, and Open Deskbar Folder to change it
  • A button per window across the middle, with the application's own picture. Click one to raise it; click the one you are in to put it away
  • At the right - processor and memory, the network, the volume, the battery, the date and the clock. Click any of them to open the application that owns it
  • The battery has a ? beside it because this machine cannot read one yet

The menu is a folder: /home/Deskbar

  • A folder per section, each holding launchers. A folder inside one is a submenu
  • Move an item between sections by dragging the file in Tracker, then Reload Menus
  • Rename an item by renaming the file; remove one by throwing it away
  • Nothing appears without a launcher. A program built later is invisible until somebody makes one - open /bin in Tracker and make it there
  • Right-click any item to edit what it starts, with what arguments, and under which picture

Windows, and the one reserved key

  • Control-W then an arrow - move the focused window
  • Control-W then Tab - focus the next one
  • Control-W then a, c, x, v - select all, copy, cut, paste in the focused control
  • Control-W twice - a literal Control-W to the application
  • Control-C - end the desktop and take the screen back to the prompt
  • A tab carries its close box at the left, where BeOS put it, and minimise and maximise at the right; the corner grip resizes, and dragging the tab moves the window

/commands lists the words the shell answers to itself.
