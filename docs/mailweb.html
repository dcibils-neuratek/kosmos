Drawn by WebKit

The newsletter's two columns, its web fonts and its colours come out as Safari would draw them. NetSurf stopped at CSS 2.1, which is why Mail needed its own fixes for newsletters.

Held means held

Until Load Pictures is pressed, no request leaves the machine: no picture, stylesheet, font or tracking pixel. The round picture was sent inside the message, so it shows at once.

Links go to JetSki

The pointer over a link puts its address in the status line. Pressing it opens the address in JetSki, and the message pane never leaves the message.

Text can be selected

Drag, double-click a word, Control-C. The blue run above is a selection.

No WebKit, no surprise

On a machine whose disk has no WebKit image yet, the message is shown as its text, and the status line says why.

Decided, 15 November

  1. Where the WebKit image lives. In /Kosmos/WebKit, a folder of its own beside Apps, Kits and Libraries, with Web Inspector's files in it. Chosen: Mail does not depend on an application.
  2. Where a link opens. In a new tab of the JetSki that is open, or a new JetSki when none is. Chosen.
