What it holds

The document's structure, from sheetsdoc; one list of undo steps saying which are the kit's and which the canvas's; the formula being typed, in a textbuf; a view's dozen numbers for each table on the screen.

What it never holds

A cell, a column or a table. One cell comes back into a reused table for the formula bar; a chart's series comes back reduced to its width in points. The grid is never a Lua value.

Libraries

Code you run, in your own process: use("/Kosmos/Libraries/..."). Structure and decisions - a few dozen things a frame, none of them a cell.

CEL0

/Kosmos/Kits

NEWS1234

The Cells Kit - the formula engine user/kits/cells/

  • The store: a table is columns of blocks of 1,024 cells, 16 bytes a cell, in pages of this process's own - 600,000 cells are 9.6 MB the collector never sees. Strings once, in a pool; a formula filled down is one formula.
  • One grammar, one parser: what is typed, the editor's colours, an XLSX's formulas and the file's - Excel's syntax, Costs!E7 naming a table; a file holds text, never compiled bytes.
  • The graph and the order: who reads whom, a range one entry per block; a change marks its dependents; Kahn's order over the dirty set alone; a cycle is #CYCLE!; a recalculation stops when its budget is spent.
  • Evaluating: postfix bytecode, about eighty functions by Excel's names, errors as values, doubles compared at fifteen digits, dates as Excel's serial days.
  • Formats, sort, filter: a value as its format shows it, Excel's codes at the XLSX's door; rows sorted and hidden in C.
  • Files: the .sheets cells, CSV, an XLSX's worksheets and shared strings - into and out of regions.
  • The grid painted: the visible cells of a table in one call, through gfx_draw.h; the first row found by block totals, so row 100,000 costs what row 10 does.

A cell is never a Lua value

Moving a loop to C is worth nothing until the data it walks stops being a Lua value. So the cells live in the kit from its first line, and Lua sees one at a time.

One grammar, never bytecode in a file

Typing, the editor's colours, the .sheets file and an XLSX go through one parser. A file holds a formula's text, checked like anything typed.

A reference names a table

Costs!E7: unique in the document, unaffected by moving between sheets, and the worksheet's name when it goes to Excel - so nothing is renamed.

A region holds the bytes

The window's pixels, the cells, and every file in or out. Messages carry the commit, a file's request, the time, and the clipboard's 1,900 bytes.
