What was removed, and what only moved

Tracker has a menu bar of three menus, a toolbar with a search field, a trail of every path segment, a status line and a sidebar. The window above has a header bar and a sidebar. Nothing is deleted. Six things move one press away:

TodayIn the window above
Menu bar: File — Open, Edit, New folder, Rename, Cut, Copy, Paste, Select all / none, Delete, Empty Trash New folder is an icon, because it is the one that makes something. The rest is the ⋮ menu and the right button, where they already are
Menu bar: Go — Back, Forward, Up, Home, Refresh Back and Forward are the two arrows. Up and Home are the breadcrumb, which opens the trail. Refresh is in ⋮
Menu bar: View — as icons / as list, sort, icon size One icon toggles icons and list. Sort and size are in ⋮, marked as they are now
Toolbar with a search field always on screen The magnifier in the sidebar’s header. Pressing it turns the header into the field
A trail of every segment: Drives › Kingston › KOSMOS HOME › photos One button saying where you are. It opens the same trail as a menu — so a deep path costs one press instead of a row of chrome on every window
A status line Gone while nothing is selected; the count appears at the foot when something is

The queries stay exactly as they are. kind:note in the search field is Tracker’s own idea and the thing it has that a file manager usually does not — it is not chrome, it is a feature, and simplifying the window is not a reason to lose it. What changes is that the field is a press away rather than permanently on screen.

The one thing I would argue about

The columns. The list view has Name, Size and Kind, and the screenshot that started this has no list view at all. I have kept it, and kept the header that sorts — because a file manager with no way to see a size is a file manager you leave to answer a question. The icons view is what opens; the list is one press.

If you would rather the list went too, say so and it goes: it is about sixty lines and they are the sixty this page is otherwise about removing.

What this does not touch

The desktop is Tracker with --backdrop, and it has no menu bar, no toolbar and no sidebar already. Icons on it, where they are dragged to, and the icon sizes chosen per place are all unchanged — and so are drag and drop, the right button reaching the application, and a place made by dropping a folder on the sidebar. Those are how the desktop works, and a screenshot is not asking about them (roadmap.md 5zi).
