Pewter - what it stands on

A second desktop for Kosmos, and the first time there is more than one. A desktop is a file in /Kosmos/Desktops naming its shell programs, the title bar the UI kit draws and where menus go; one window manager draws every desktop, and a chooser at every boot picks one. Kosmos's own applications run on Pewter unchanged, in its Platinum chrome, with their menus at the top of the screen. A third desktop is a third file and the programs it names.

B - a desktop chosen at boot

  1. B1 The window manager is asked for nothing, so it starts the chooser, which reads /Kosmos/Desktops and the desktop setting.
  2. B2 A click or Return: the setting saved, desktop{name="pewter"} posted, the chooser ends.
  3. B3 The window manager reads Pewter.desktop, applies its chrome, menus and look, and starts its shell.
  4. B4 Each window learns its chrome in the reply to its open, before its first frame.
  5. B5 The chooser stays as the loader: a launch event for each piece and startup application - starting, ready at its first window, or failed - and it ends when all are in, or a second and a half on.

M - a menu title pressed, inside a frame

  1. M1 The menu bar draws the titles the last watch event brought: no asking in a repaint.
  2. M2 A press: menu_open posted - which window, which title, where. Nothing waited for.
  3. M3 The window manager posts menubar to that window, as for a direct one today.
  4. M4 The application's kit opens its own menu under the title; its items never left it.
