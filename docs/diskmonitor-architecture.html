Disk Monitor - what it stands on

It counts nothing itself. Each server that holds a drive counts what it reads and writes, in total and for each program that asks, and answers one door under the drive's path: .device and .programs. The graphs and the card are the kit's, as Network Monitor made them. Disk Monitor reads each drive once a pace and draws.

IPC, regions

R - a read or a write

  1. R1 the server adds the bytes and the time taken to the drive's totals, as diskfs does for Disk Benchmark.
  2. R2 and to its caller's row, by the process id it learned when that program first asked, with the path - nothing allocated per request.

W - the window, once a pace

  1. W1 .device for each drive in the list, .programs for the one shown.
  2. W2 rates as the difference between two readings; time a request as time over requests.
  3. W3 a column on each graph, the programs busiest first, a paint.
