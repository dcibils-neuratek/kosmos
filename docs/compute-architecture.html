The Compute Kit - what it stands on

A Lua program writes a kernel as the GPU's own assembly, gives it buffers and a grid, and gets a ticket back. The assembler is Lua, in the program; the kit is C, in the program; the driver checks every kernel before it runs, so a kernel can touch only the buffers it was handed. Numbers and pixels never travel in a message: they are in buffers the program and the GPU both see.

F - a frame of GPU Fractal

  1. F1 the view - centre, scale, iterations - into the run's constants.
  2. F2 compute.run: one message - kernel, buffer 0, constants, 64 × 768 groups.
  3. F3 the driver writes about seventy dwords into a state page and the ring; answers with a ticket.
  4. F4 the walker hands out 786,432 threads.
  5. F5 each works out its pixel's escape and writes its colour.
  6. F6 the program asks for the ticket as the window paints; the pixels are already in the buffer the window shows.
