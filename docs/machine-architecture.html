This Machine - what it stands on

It finds nothing itself. One new library gathers every source the system already has into one list of devices - kind, name, maker, place, driver, state, what it is doing - and the window draws it. The one thing nothing could say before is every USB device on every port, driven or not: the USB driver knows it and wrote it only to the log; one verb lets a program ask.

O - the window opened

  1. O1 asks devices.list(), draws the cards.
  2. O2 the library reads each source once and merges: a PCI device a driver claimed, the USB devices on it, what each server says it is doing.
  3. O3 one message to the USB driver: its list, copied from what it keeps.
  4. O4 one sys.bus(): up to 64 devices, each claimed or not.

R - every two seconds

  1. R1 the lines that move - speed, clock, memory, rates - and the USB list, so a stick plugged in appears.
