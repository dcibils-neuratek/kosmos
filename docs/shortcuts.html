Shortcuts

An application, in the dock and the Kosmos menu, that shows every key works everywhere in Kosmos - the desktop's, the windows', the screen's and text editing's - grouped, searchable, and drawn as keys rather than written as words. Diego, 10 October 2026: "a better shortcut app to show all available shortcuts in a nice way", "right now is very raw", "a real app that can be launched from the dock, called Shortcuts", "can be also extended as a help, cheatsheet window in the future", "make it look nice".

Every system-wide key has Change: pressed, the row listens for new keys. Keys another shortcut has are said in words, with the choice - take them, and the other is left without keys, or press others. A changed row says what it was, and Default puts it back. Text editing's keys and Control-W's are shown and not changed here (below).

Where the keys come from

Shortcuts is an index of the keys that work everywhere - the system's, not each application's. The desktop's, the windows' and the screen's keys are the window manager's table (user/lib/wm/keys.lua), which it already answers when asked, so they are always the keys in force; text editing's are the UI kit's, which every field answers. Diego, 10 October 2026, on a first design that had each application declare its own: "The shortcuts app it's just an index of all system wide key combinations that do something like taking a screenshot, maximize windows etc".

Later: help and the cheat sheet

"Print as a cheat sheet" writes the whole list as a page (a PDF, through the PDF Kit) to keep beside the keyboard. The same window can grow a Help part - a page for each application, with its shortcuts at the end - which is the "help, cheatsheet window in the future" Diego named; nothing of that is built now.

Decided

Agreed on 10 October ("Mockup looks great"): new shortcuts are Super chords only; a global one is answered before the application in front, and a Super chord nobody made global reaches the application, which is where its own keys live - Mail's Super N for a new message (Diego: "Shortcuts are global keys mapping", "Then every app has its own local app key shortcuts like super+n in mail app"); text editing's and Control-W's keys are shown and not changed here. A shortcut opens an application or program, or does one of the things the system's keys do - close, hide, the switcher, a capture, and Magnet's once it is built.

They persist, as a user setting (Diego, the same evening: "And changes should persist", "So it's a user setting"): /Home/Preferences/shortcuts, through the settings kit like every other preference, read by the window manager whenever it starts. It holds only what was made or changed here, each entry saying in full what it does, so a system key added in a later version still arrives.
