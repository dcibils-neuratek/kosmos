Quick Look

Space on a file in Tracker shows it, without opening anything: a panel over the window, the file fitted in it. Space again, or Escape, and it is gone. The arrows move through the folder with the panel open, and it shows each file as the selection reaches it. Pictures first; PDFs, songs and films after, as Diego asked. Every file here is made up.

The keys

SpaceIn Tracker, with a file selected: the panel. With it open: closes it.
EscCloses it.
↑ ↓The file above or below in Tracker, shown in the same panel - Tracker's selection moves with it, so closing leaves you on what you last looked at.
ReturnOpens it, as Open with does, and closes the panel.

What it is made of

A library, not Tracker's own code - /Kosmos/Libraries/preview.lua, a view that shows a file fitted to it. Tracker's Quick Look is its first user; the Open window's preview pane and Mail's attachments are the next two who want exactly this, so it is written once (kits supply, applications orchestrate). It decodes nothing itself: pictures through pictures.lua, read into a region as the window manager and Photo read them; PDF pages through the PDF Kit, as Reader draws them; songs through the audio kit and the decoders Music plays with; films through video.lua, as Video plays them. Nothing new is written for a format.

The panel is a window of Tracker's, floating above it, sized to what it shows. Its pixels are drawn in C by the kits; Lua decides only what goes where. A picture larger than the panel is scaled down by the gfx kit's scaler, once, when it is shown.

For Diego to decide

3. The order to build: pictures (and anything else as its icon), then PDF, then songs, then films - as you said - each its own step with its own test.
