P - a guest printing

  1. P1 the guest writes its serial port's data register, which nothing maps: it stops, an exit.
  2. P2 vmm puts the byte in its console ring and runs it again.
  3. P3 a window watching asks for what is new, twice a second; a Terminal attached, when it has drawn - a message each, whatever the guest prints.
  4. P4 the last lines on the card; the whole console in its tab.
