# The FBX files `tools/test_fbx.c` reads, one a line: a name, the FBX under
# ufbx's `data/` at the commit vendored in `runtime/upstream/ufbx/` and its
# sha256, the OBJ its program exported of the same scene and its sha256
# where there is one, and what the file exercises.
#
# They are ufbx's own test files - written by the programs named, not by
# hand - and an OBJ beside one is the geometry that program says it has, in
# the file's own axes and unit: the check is that ours, turned into Y up
# and metres, is the same shape in the same place.
#
# About 350 KB, so `tools/fetch_conformance.py fbx` puts them in
# `build/downloads/fbx-conformance/` and holds each to its sum. The sums
# are of the files as fetched on 26 September 2026, from
# raw.githubusercontent.com at commit 26a482ae66871d7de36eb722aa060bce95bce274.
#
