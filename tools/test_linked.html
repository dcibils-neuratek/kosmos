You followed a link

Which means the layout kept its boxes, the click was turned into a point on the page, link_at found the run under it, the relative address was resolved against the one this browser was already on, and the whole fetch happened again. Six separate things, and the only way to know all six work is to arrive here.

What is still missing

  • The cascade. libcss parses, selects and answers, and nothing asks it. Colour, font size, weight and slant should come from the computed style rather than from the tag's name.
  • A box model. No margins, no padding, no borders, no width, no floats. Blocks are stacked and inline content flows; everything else about geometry is a constant in a header.
  • Images. stb_image is already vendored for the PDF reader, so this is plumbing rather than a decoder.
  • Forms. A field is a box that takes keys, which needs boxes to be addressable from outside the layout - the same step that made this link clickable.
A word is where a font change, a link's hit rectangle and a selection all attach. That is why layout keeps its runs.
