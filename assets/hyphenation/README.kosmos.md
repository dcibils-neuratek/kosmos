# Hyphenation patterns, vendored

Liang's patterns as the hyph-utf8 package publishes them for TeX, used by
Kosmos Write's setting (`user/lib/hyphen.lua`, `docs/write.md` W4e). Each
file is byte for byte what the package ships; each language's terms are in
the `LICENSE.` file beside it, taken from the header of its `.tex` source.
